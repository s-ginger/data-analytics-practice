1. Что такое база данных?

База данных (БД) — это организованное хранилище информации.

Например, интернет-магазину необходимо хранить:

    Названия товаров.

    Категории товаров.

    Цены.

    Количество проданных товаров.

    Даты продаж.

Вместо хранения информации в обычных текстовых файлах используются специальные системы управления базами данных.

SQLite — небольшая система управления реляционными базами данных. Она позволяет хранить информацию в одном файле.

В нашем проекте база данных будет называться shop.db.

4. Создание базы данных

Откройте setup_db.py и напишите:

import sqlite3

conn = sqlite3.connect("shop.db")
cursor = conn.cursor()

cursor.execute("""
CREATE TABLE IF NOT EXISTS sales (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    product TEXT NOT NULL,
    category TEXT NOT NULL,
    price INTEGER NOT NULL,
    quantity INTEGER NOT NULL,
    sale_date TEXT NOT NULL
)
""")

conn.commit()
conn.close()

print("База данных создана!")

Объяснение

sqlite3.connect() — подключается к базе данных.

cursor() — создаёт объект для выполнения SQL-команд.

CREATE TABLE — создаёт таблицу.

PRIMARY KEY — определяет уникальный идентификатор записи.

NOT NULL — запрещает пустые значения.

commit() — сохраняет изменения.

close() — закрывает соединение.

После запуска должен появиться файл shop.db.
5. Добавление информации

Дополните программу следующим кодом. Разместите его до закрытия соединения с БД:

sales = [
    ("Ноутбук", "Техника", 320000, 2, "2026-11-01"),
    ("Мышь", "Аксессуары", 6500, 8, "2026-11-01"),
    ("Монитор", "Техника", 95000, 3, "2026-11-02"),
    ("Клавиатура", "Аксессуары", 14000, 5, "2026-11-02"),
    ("Наушники", "Аксессуары", 23000, 4, "2026-11-03")
]

cursor.executemany("""
INSERT INTO sales
(product, category, price, quantity, sale_date)
VALUES (?, ?, ?, ?, ?)
""", sales)

conn.commit()

Важно: добавление записей выполняйте только один раз. При повторном запуске вставка создаст дубликаты.

Выручка — общая сумма денег от продаж.

Выручка = цена × количество

В реальных информационных системах данные не всегда бывают правильными.

Например:

    Одна продажа случайно записана два раза.

    Цена товара указана неправильно.

    Отсутствует дата продажи.

    Количество товара указано неверно.

    В таблице встречается необычно большое значение.

Такие проблемы могут приводить к неправильным выводам.
1. Что такое очистка данных?

Очистка данных — процесс поиска и исправления некорректной информации.

Для анализа качества данных часто используются:

isna() — поиск отсутствующих значений.

duplicated() — поиск повторяющихся строк.

mean() — среднее арифметическое.

median() — медиана.

max() — максимальное значение.

min() — минимальное значение.
2. Поиск пропусков

Откройте analysis.py.

Добавьте:

print(df.isna().sum())

Программа покажет количество пропусков в каждом столбце.
3. Поиск дубликатов

print(df.duplicated().sum())

Обратите внимание: если каждая запись имеет уникальный id, полные строки могут не совпадать даже при повторении остальных полей.

Для поиска повторяющихся продаж можно использовать:

columns = [
    "product",
    "category",
    "price",
    "quantity",
    "sale_date"
]

print(df.duplicated(subset=columns).sum())

Не удаляйте совпадения автоматически: две одинаковые продажи могут быть настоящими.
4. Среднее значение и медиана

print("Средняя цена:", df["price"].mean())

print("Медиана:", df["price"].median())

Среднее арифметическое — сумма значений, разделённая на их количество.

Медиана — центральное значение упорядоченного набора данных.

Медиана часто меньше зависит от очень больших или очень маленьких значений.
5. Исследование выбросов

Выброс — значение, которое заметно отличается от остальных наблюдений.

Например, если большинство товаров стоят от 5 000 до 300 000 тенге, цена 15 000 000 тенге требует проверки.

1. Что такое дашборд?

Дашборд — это информационная панель, на которой представлены основные показатели, графики и элементы управления.

Например, аналитическая система магазина может показывать:

    Самые популярные товары.

    Продажи по категориям.

    Динамику выручки.

    Фильтры по категориям и товарам.

2. Что такое Streamlit?

Streamlit — библиотека Python для создания интерактивных веб-приложений.

Она позволяет создавать интерфейсы без необходимости самостоятельно писать HTML, CSS и JavaScript.
3. Что такое Plotly?

Plotly — библиотека для построения интерактивных графиков.

Пользователь может наводить курсор на элементы графика, просматривать значения и взаимодействовать с диаграммами.

st.metric(

Метод st.metric() отображает числовой показатель.
7. Добавление фильтра

categories = sorted(df["category"].unique())

selected = st.multiselect(
    "Выберите категории",
    categories,
    default=categories
)

filtered = df[df["category"].isin(selected)]

multiselect() позволяет выбрать одну или несколько категорий.

isin() проверяет, принадлежит ли значение выбранному списку.

Важно: после добавления фильтра показатели и графики должны рассчитываться по filtered, а не по исходному df.
